Fabric mod for Minecraft 1.21.11

Carry it through anything.

Aim at a mob and press C. It rides on your shoulders through teleports, other dimensions, falls, logouts, server restarts and your own death, until you press C again.

Get it on GitHub

Needed on the server. On the client it adds the key and draws the mob; players without it can still join, they just see bare shoulders.

The mob stays on your shoulders through

  • Teleports
  • The Nether
  • The End
  • Falls
  • Elytra flight
  • Logouts
  • Restarts
  • Death

Nothing can knock it off, because while you carry it the mob is not in the world at all. It lives in your player save file. Set keepOnDeath to false if you would rather it drop where you fell.

How it works

A mob becomes a few lines of NBT, then a mob again.

  1. I.

    Pick up

    The mob is written as NBT into your player data and removed from the world. From then on it cannot be hurt, despawn or fall off.

  2. II.

    Carry

    Your client receives that NBT and builds a display-only copy on your shoulder, with the right variant, age, collar and name tag.

  3. III.

    Put down

    Press C again and the entity is rebuilt from the same NBT, in front of you or at your feet if that spot is taken. Same UUID, same health, same inventory, same villager reputation.

What you can carry

If a shepherd could lift it, so can you.

Goes on your shoulders

  • Passive mobs up to 1.0 × 1.5 blocksHitbox width × height, both configurable
  • Anything you can hit, up to 4.5 blocks awayYou aim at it like an attack, and walls block the aim
  • Your own petsA lead you were holding comes back to your inventory
  • Hostile mobs, if the server allows itallowHostileMobs is off by default

Stays on the ground

  • PlayersNever, whatever the config says
  • Someone else’s pet, or a mob they lead or rideUnless allowCarryingOthersPets is on, for pets
  • A villager in the middle of a tradeWait for the other player to close the menu
  • Invulnerable mobsServer NPCs and adventure-map merchants
  • Ender Dragon, Wither, WardenThe default blacklist, on top of the size limit

Controls

C

One key does both

Aim at a mob and press C to pick it up. Press it again to set it down. Rebind it under Options → Controls → CarryMoby.

Commands

/carrymoby infoShows what you are carrying
/carrymoby dropDrops your mob, if something went wrong
/carrymoby drop <players>Drops other players’ mobs Operator
/carrymoby reloadReloads the config file Operator

Configuration

Every limit lives in one file.

config/carrymoby.json, created on first launch

KeyDefaultWhat it does
allowHostileMobsfalseLets players carry zombies, creepers and friends
maxWidth1.0Largest hitbox width, in blocks
maxHeight1.5Largest hitbox height, in blocks
pickupRange4.5How far away you can pick a mob up, in blocks
allowCarryingOthersPetsfalseLets players take someone else’s tamed animal
keepOnDeathtrueWhen false, the mob drops where you died
slownessFactor0.0Speed penalty while carrying; 0.15 means 15% slower
blacklist3 mobsNever carryable: Ender Dragon, Wither, Warden

Install

Three files in the right places.

  1. I.

    Fabric Loader

    Version 0.19.5 or newer, for Minecraft 1.21.11, on Java 21.

  2. II.

    Fabric API

    Drop it into your mods/ folder.

  3. III.

    CarryMoby

    Put carrymoby-1.0.0.jar into mods/, on the server and on each client that wants to see the mobs.

Building from source: ./gradlew build writes the jar to build/libs/. ./gradlew runGameTest checks every carry rule headless.
